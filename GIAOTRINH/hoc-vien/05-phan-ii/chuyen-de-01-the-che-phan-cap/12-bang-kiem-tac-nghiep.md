# Chuyên đề 1 mục 12 — Bảng kiểm tác nghiệp

## Tinh thần

PHẢI THỰC HÀNH. Dùng trước khi trình ký hồ sơ phân cấp / phân chia nguồn thu. Một ô «Chưa» = chưa trình. [[GIAOTRINH/hoc-vien/05-phan-ii/chuyen-de-01-the-che-phan-cap/00-index|CĐ 1]].

## Nội dung chương trình đem lại

*(Bảng không gắn wikilink alias trong ô.)*

| Nội dung | Đạt | Chưa |
|---|---|---|
| Văn bản phân cấp đang áp dụng đã được kiểm tra ngày hiệu lực? | | |
| Đã xác định đúng dòng tỷ lệ tương ứng với địa bàn của đơn vị mình? | | |
| Đã phân biệt rõ khoản thu hưởng 100% và khoản thu phân chia theo tỷ lệ? | | |
| Số thu ngân sách xã được hưởng đã tính sau khi nhân tỷ lệ phân chia? | | |
| Đã đối chiếu tỷ lệ trong văn bản với tỷ lệ đang chạy trên hệ thống? | | |
| Đã đối chiếu số liệu với Kho bạc Nhà nước và cơ quan Thuế trong kỳ gần nhất? | | |
| Mã đơn vị có quan hệ với ngân sách đã đúng với đơn vị hiện tại? | | |
| Trách nhiệm tham mưu, kiểm soát nội bộ đã được phân công bằng văn bản? | | |
