# Tài liệu tập huấn

## Đối tượng và mục đích

Công chức đang học / ôn / giảng khóa. Trang này trả lời: *file gốc nào là tài liệu chính, khi nào đọc `.md` wiki, khi nào mở `.docx`/`.pdf`*. Bản đọc Obsidian (`.md`) cạnh file gốc. Giữ nguyên nguồn. Chuyển bằng skill `tailieu-to-md`.

Hai file dưới đây là **cặp bắt buộc** trên mọi hub gói. Phụ lục và ontology không thay thế cặp này.

## Khi nào mở trang này

- Cần nhảy thẳng vào hai file chính (không qua mục lục buổi / CĐ).
- Cần in / gửi file gốc cho học viên.
- Cần danh sách tham gia tập huấn hoặc TBox ontology.
- Wiki đã đủ thứ tự hỏi — cần đối chiếu đoạn gốc (bảng tỷ lệ, tình huống, sổ tay).

**Đọc file gốc khi nào:** khi cần bảng / tình huống / sổ tay nguyên văn, hoặc khi giảng đúng heading nguồn. Việc hàng ngày và thứ tự hỏi ở [[TIMHIEU/index|Tìm hiểu — nắm → nghĩ → làm]] / [[hub-goi|Hub gói — lối vào nhu cầu]] — không thay bằng cuộn hết `.md`.

## Vận dụng

1. **Làm đúng** — mở đúng file + đúng heading (`# BUỔI n` hoặc chuyên đề), không trộn hai trục.
2. **Tự kiểm** — lấy bảng kiểm / cây quyết định từ học viên, đối chiếu trình tự cẩm nang.
3. **Giải trình** — trích heading nguồn + Điều trên [[Vanbanquydinh/index|Văn bản quy định dẫn chiếu]], không chép miệng.
